# chai-system · 柴记账管理端

Vue 3 + TypeScript + Vite + Vue Router 的 Web 管理端。当前已实现演示页面、真实管理员认证、用户与业务只读查询、分类管理和操作日志接线。**生产部署尚未完成，不可直接作为生产管理系统使用。**

## 当前范围

- 已实现：登录表单校验、演示会话、路由跳转、菜单折叠、退出、会话过期、概览指标、7 / 30 天趋势、模拟服务状态及示例操作摘要。
- 第二批已实现：用户列表筛选与分页、用户详情抽屉；账本 / 记账记录 / 预算查询；跨页带参、单条演示授权与重新隐藏。
- 第三批已实现：分类管理、操作日志详情、系统状态详情、反馈指引，全部管理菜单已开放。分类变更仅保留在本页内存，日志与状态为明确标识的固定演示样例。
- 真实认证接线：login / me / logout、同源 HttpOnly Cookie、路由身份校验、过期与退出异常处理。用户、业务查询、分类管理和操作日志使用独立真实接口；系统状态和用户反馈仍为待接入页面，演示模式不是接口失败后的降级机制。
- `prototype/` 保留上一阶段已验收的静态原型，不修改或替换其源码。正式前端仅复用其中的 CSS 与可信 SVG 图标路径。

## 本地开发

要求 Node.js 22.12+、pnpm 10+；本次环境使用 Node.js 22.18.0 / pnpm 11.5.3。依赖版本已固定在 `package.json` 与 `pnpm-lock.yaml`。

```powershell
pnpm install --ignore-scripts
pnpm dev
```

默认仅监听本机 `127.0.0.1:5173`。端口占用时会报错，不自动切换端口或关闭其他进程。入口为 `/login`，概览为 `/dashboard`。

本轮默认端口 5173 已被其他服务占用，保持其不变，使用 `pnpm dev --port 5174` 启动开发预览：`http://127.0.0.1:5174/login`。生产构建本地预览使用 `http://127.0.0.1:4173/login`。

未设置 `VITE_AUTH_MODE` 时，开发服务默认为 demo；构建默认为 api。模式只由启动/构建配置决定，不接受 URL、浏览器存储或界面开关覆盖。

仅演示模式使用账号 `demo-admin`，演示口令自行填写不少于 6 个字符。**演示模式不要输入真实密码**；演示口令不发送、不持久化，不验证真实身份。真实模式账号必须先经单独授权初始化，不能用 demo-admin 的演示规则登录。

## 第四批：真实管理员认证接线

### 两种模式严格隔离

- `VITE_AUTH_MODE=demo`：沿用原有演示会话与全部七个演示页面，不调用认证 API。
- `VITE_AUTH_MODE=api`：调用同源 `/api/v1/admin/auth/login`、`me`、`logout`。Cookie 由浏览器自动携带，应用不读取 document.cookie，不保存密码、令牌或真实身份到 localStorage/sessionStorage。
- 真实模式不接受旧演示会话；进入受保护路由必须通过 me 校验，不按前端角色或显示名称推断权限。
- 真实模式的所有业务路由都使用独立待接入页面，不挂载或请求演示业务集合，不显示虚构统计、流水、分类修改成功或生产正常状态。
- 接口 401 / 403 / 404 / 422 / 429 / 503、网络中断、超时、非 JSON 或异常结构均有明确处理，不切换成演示。服务端原始错误文本不直接展示或记录，登录凭据不写入日志。
- 请求固定同源、禁止跟随重定向、禁用缓存，10 秒超时，不自动重试登录或退出；429 的数字 Retry-After 最多按 3600 秒展示等待。

### 会话校验与退出

- 成功登录仅保存内存身份摘要；刷新后重新请求 me。切换受保护路由和窗口重新获得焦点时复核身份；可见页面定时检查到期，并约每分钟复核一次。
- 重复 me 请求合并；请求代次和 AbortController 防止旧响应覆盖新状态，退出会取消未完成的身份校验。未验证期间不渲染管理内容。
- 密码支持粘贴和浏览器密码管理器，不在应用中持久化。真实模式使用 username / current-password 自动填充标识；输入校验按后端的字符、长度与控制字符限制执行。
- 退出只有收到成功响应或服务端 401 后才显示已退出。网络/存储/审计错误可能意味着服务端处理结果不确定，进入“退出尚未确认”页面，不能假装会话已撤销。
- 为避免刷新后忘记未确认退出，仅在 sessionStorage 保存 `chai-system.admin-logout-pending.v1=1` 这一非敏感意图标记。它不含身份、密码、令牌或权限，不能用于放行页面。确认退出后删除；标记存在时必须重试退出，不能通过登录页自动绕过。
- 浏览器存储不可用时，退出意图只能保留在当前页面；界面明确提示此限制。即使刷新失去标记，仍必须通过服务端 me 校验，不能使用本地信息取得权限。

### 本机接线配置

`.env.example` 仅提供配置说明，本批不创建实际环境文件，也不初始化数据库或真实账号。

| 变量 | 用途 |
| --- | --- |
| `VITE_AUTH_MODE` | api / demo；其他非空值会阻止启动或构建 |
| `ADMIN_PROXY_TARGET` | 可选开发代理，只允许无认证信息、无路径的本机 HTTP/HTTPS 来源；不进入前端包 |

开发代理转发 `/api/v1/admin/auth`、用户与业务查询、分类管理及 `/api/v1/admin/audit-logs`，不自动连接生产。后端 `ADMIN_ORIGIN` 必须等于浏览器访问前端的准确来源，例如前端端口 5174 时为 `http://127.0.0.1:5174`；不能以修改 Origin 或放宽后端校验绕过限制。代理目标不能指向前端自己的监听地址。

在单独确认后，通过启动终端环境变量或本地环境文件选择 api 并指定已准备的本机后端，再重启开发服务。生产由经审核的反向代理提供同源 API；此处没有修改后端 CORS、Nginx 或任何生产配置。
